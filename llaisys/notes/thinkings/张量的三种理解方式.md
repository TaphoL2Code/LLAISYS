## 1. 数学家视角：多重线性映射

### 核心定义

对数学家而言，张量是一个**多重线性映射**（multilinear map）。它不是"数据"，而是一个"函数"——将多个向量映射到一个标量。

$$
设 V 是数域 \mathbb{F} 上的 n 维向量空间，V^* 是其对偶空间（线性泛函空间）。
$$

$$
(r, s) 型张量是从 r 个对偶向量和 s 个向量的笛卡尔积到 \mathbb{F} 的多重线性映射：
$$



$$
T: \underbrace{V^* \times \cdots \times V^*}_{r \text{ 个}} \times \underbrace{V \times \cdots \times V}_{s \text{ 个}} \to \mathbb{F}
$$

- r 称为**逆变阶数**（contravariant rank）
- s 称为**协变阶数**（covariant rank）
- 总阶数 r + s 称为张量的**秩**（rank）或**阶**（order）

### 具体示例

**标量（scalar）= (0,0)$型张量：**
$$
标量本身就是一个从空笛卡尔积到 \mathbb{F} 的映射。它不依赖任何向量。
$$
**向量（vector）= (1,0) 型张量：**
$$
一个向量 v \in V可以看作映射 v: V^* \to \mathbb{F}，即 v(\omega) = \omega(v)。
$$

$$
给定一个对偶向量（线性泛函），返回一个标量。这就是“向量是对偶空间上的线性泛函”的含义。
$$
**对偶向量（covector）= (0,1) 型张量：**
$$
一个线性泛函 \omega \in V^*本身就是映射 \omega: V \to \mathbb{F}。
$$
**矩阵（matrix）= (1,1) 型张量：**
$$
给定 (v, \omega)，返回标量 \omega(Av)。即 T(\omega, v) = \sum_{i,j} T^i_j \cdot \omega_i \cdot v^j。
$$
**双线性形式（如内积）= (0,2) 型张量：**
$$
给定两个向量 (u, v)，返回标量 \langle u, v \rangle = \sum_{i,j} g_{ij} u^i v^j。例如欧氏内积的度量张量 g_{ij} = \delta_{ij}。
$$
**(1,2) 型张量（如李括号/曲率张量）：**
$$
给定 (\omega, u, v)，返回标量。例如黎曼曲率张量 R(\omega, X, Y, Z) 是 (1,3) 型。
$$


### 张量积

$$
数学上，张量通过张量积（tensor product）\otimes 构造：
$$



$$
(v \otimes \omega)(\alpha, x) = v(\alpha) \cdot \omega(x) = \alpha(v) \cdot \omega(x)
$$

两个张量的张量积会增加它们的阶数。例如：
- $$
  两个向量的张量积 v \otimes w 是 (2,0) 型张量
  $$

  
- $$
  一个向量和一个对偶向量的张量积 v \otimes \omega 是 $(1,1)$ 型张量
  $$

  

### 爱因斯坦求和约定

数学家使用分量表达式和爱因斯坦求和约定：
- $$
  逆变分量（上标）：T^{ijk\ldots}_{abc\ldots}
  $$

  
- $$
  协变分量（下标）：T_{abc\ldots}^{ijk\ldots}
  $$

  
- $$
  上下标成对出现表示求和（哑指标）：T^i_j v^j = \sum_j T^i_j v^j
  $$

  

### 数学家视角的关键要点

| 概念 | 含义 |
|------|------|
| 张量是映射 | 不是数据容器，是多线性函数 |
| 阶 = 输入向量的数量 | 阶数 r+s 表示映射接收多少个参数 |
| 空间依赖性 | 张量定义在特定向量空间 V 上，脱离 V 无意义 |
| 坐标无关 | 张量是几何对象，其存在不依赖于任何坐标系的选择 |

## 2. 物理学家视角：坐标变换下的几何对象

### 核心定义

物理学家关心的是：**当坐标系改变时，物理量如何变换？**

张量是满足特定变换规则的几何对象。"张量" = "按张量方式变换的量"。

### 坐标变换

$$
设坐标系从 \{x^i\} 变为 \{\bar{x}^i\}，变换矩阵为：
$$



$$
\Lambda^i_j = \frac{\partial \bar{x}^i}{\partial x^j}, \quad (\Lambda^{-1})^i_j = \frac{\partial x^i}{\partial \bar{x}^j}
$$

**逆变张量（contravariant，上标）变换规则：**

$$
\bar{T}^{i} = \Lambda^i_j T^j = \frac{\partial \bar{x}^i}{\partial x^j} T^j
$$

**协变张量（covariant，下标）变换规则：**

$$
\bar{T}_i = (\Lambda^{-1})^j_i T_j = \frac{\partial x^j}{\partial \bar{x}^i} T_j
$$

**一般 (r,s) 型张量变换规则：**
$$
\bar{T}^{i_1\ldots i_r}_{j_1\ldots j_s} = \Lambda^{i_1}_{a_1} \cdots \Lambda^{i_r}_{a_r} \cdot (\Lambda^{-1})^{b_1}_{j_1} \cdots (\Lambda^{-1})^{b_s}_{j_s} \cdot T^{a_1\ldots a_r}_{b_1\ldots b_s}
$$

$$
每个上标按 \Lambda变换，每个下标按 \Lambda^{-1}变换。
$$



### 物理直觉

| 类型 | 例子 | 物理含义 |
|------|------|------|
| 标量（(0,0) 型） | 温度 T、质量 m | 坐标变换下不变 |
| 逆变向量（(1,0) 型） | 速度 v^i、位移 dx^i | 像坐标微分一样变换 |
| 协变向量（(0,1) 型） | 梯度 \partial_i \phi、力 | 像偏导数一样变换 |
| (1,1) 型 | 应力-能量张量 | 混合变换 |
| (0,2) 型 | 度量张量 g_{ij} | 定义距离和内积 |
| (2,0) 型 | 逆度量 g^{ij} | 升指标 |

### 提升和降低指标

$$
物理学家使用度量张量 g_{ij} 在逆变和协变之间转换：
$$



$$
\begin{aligned}
v_i &= g_{ij} v^j \quad &\text{(降指标：逆变 → 协变)} \\
v^i &= g^{ij} v_j \quad &\text{(升指标：协变 → 逆变)}
\end{aligned}
$$

$$
在欧氏空间中 g_{ij} = \delta_{ij}，逆变和协变分量相同，这也是大多数深度学习从业者不区分两者的原因。
$$



### 符号约定

| 指标位置 | 变换方式 | 物理直觉 |
|:--:|------|------|
| 上标 T^{i} | 逆变，按 \frac{\partial\bar{x}}{\partial x} | "随坐标方向变化" |
| 下标 T_i | 协变，按 \frac{\partial x}{\partial\bar{x}} | "与坐标方向相反变化" |

### 物理学家视角的关键要点

| 概念 | 含义 |
|------|------|
| 变换规则定义张量 | "张量就是这样变换的东西" |
| 坐标系相关 | 分量数值依赖坐标系，但张量本身是客观的 |
| 物理不变性 | 物理定律必须用张量方程表达（坐标无关） |
| 广义相对论 | 时空本身就是 (0,2)型度量张量场 |

## 3. 计算机科学家视角：多维数组

### 核心定义

对计算机科学家而言，张量就是一个**多维数组**（multidimensional array），或更具体地说，是一个**带有形状、步长和数据类型的多维数组**。

```cpp
// C++ 中的张量概念（以 LLAISYS 为例）
struct Tensor {
    size_t   ndim;      // 维度数（阶数）
    size_t*  shape;     // 形状 [d0, d1, ..., d_{n-1}]
    ssize_t* strides;   // 步长（用于跨步访问和视图）
    DataType dtype;     // 数据类型 F32/F16/BF16/I32...
    void*    data;      // 原始数据指针（平坦线性内存）
    Device   device;    // 所在设备 CPU/GPU
};
```

### 阶与形状的对应

| 数学/物理 | 计算机科学 | 形状示例 | 典型用途 |
|:--:|:--:|------|------|
| 0 阶张量（标量） | 0-d 数组 | `[]` 或 `[1]` | loss 值、学习率 |
| 1 阶张量（向量） | 1-d 数组 | `[d]` | embedding、bias |
| 2 阶张量（矩阵） | 2-d 数组 | `[m, n]` | 权重矩阵、注意力分数 |
| 3 阶张量 | 3-d 数组 | `[B, L, D]` | batch 序列、图像 `[C, H, W]` |
| 4 阶张量 | 4-d 数组 | `[B, H, L, L]` | 多头注意力 `[B, Nh, L, D]` |
| 5 阶张量 | 5-d 数组 | `[B, Nh, Lq, Lkv, D]` | 分组注意力 KV |

### 内存布局：Row-Major vs Column-Major

计算机内存是**一维线性**的。多维数组需要**布局映射**到一维：

**Row-Major（行优先，C/C++/PyTorch 默认）：**
```
a[i][j] = data[i * stride[0] + j * stride[1]]
         = data[i * N + j]
```
最后维度最快变化。矩阵 `[[1,2], [3,4]]` 在内存中为 `[1, 2, 3, 4]`。

**Column-Major（列优先，Fortran/MATLAB 默认）：**
```
a[i][j] = data[j * stride[1] + i * stride[0]]
         = data[j * M + i]
```
第一个维度最快变化。矩阵 `[[1,2], [3,4]]` 在内存中为 `[1, 3, 2, 4]`。

### 步长（Strides）

![](C:\Code\LLAISYS\llaisys\notes\thinkings\image\Snipaste_2026-06-03_15-23-03.png)

步长是计算科学中特有的概念——它定义了一个维度的元素间在内存中跳过的字节/元素数。

```
张量形状: [3, 4]    (3行 4列)
连续布局 strides: [4, 1]

data: [a00, a01, a02, a03, a10, a11, a12, a13, a20, a21, a22, a23]
       |---- stride[0]=4 ----|

访问 a[1][2]: offset = 1 * 4 + 2 * 1 = 6 → data[6] = a12
```

步长的强大之处在于：**零拷贝视图操作**——transpose、slice、broadcast 只需修改 shape 和 strides，无需移动数据。

**Transpose 示例：**
```
原张量 shape=[3,4], strides=[4,1]
Transpose → shape=[4,3], strides=[1,4]  ← 仅交换步长！
```

**Slice 示例：**
```
取第2行: shape=[4], strides=[1], offset = 1*4 = 4
直接指向 data[4..7]，完全零拷贝。
```

### 内存连续性

| 类型 | 含义 | 示例 |
|------|------|------|
| **C-contiguous** | strides 按 row-major 递减 `[d1*d2, d2, 1]` | PyTorch 默认 |
| **Fortran-contiguous** | strides 按 column-major 递增 `[1, d0, d0*d1]` | NumPy order='F' |
| **Non-contiguous** | 任意 strides（view/transpose/slice 后） | 转置后 `strides=[1,4]` |

### 广播（Broadcasting）

从右向左对齐两个张量的形状，维度为 1 的可以"展开"匹配另一个。这是深度学习框架特有的需求：

```python
a: [3, 1, 4]
b: [5, 4]
→ a broadcast: [3, 5, 4]  # dim 1 从 1 展开到 5
→ b broadcast: [3, 5, 4]  # 左侧补维度到 3
```

### CPU vs GPU 张量

| 维度 | CPU 张量 | GPU 张量 |
|------|------|------|
| 内存位置 | 主存 (DRAM) | 显存 (VRAM, HBM) |
| 访问延迟 | ~100 ns | ~几百 cycles（核心内） |
| 跨设备复制 | PCIe 带宽瓶颈 | 设备内无瓶颈 |
| 内存管理 | `malloc/free` | `cudaMalloc/cudaFree` |
| 对齐要求 | 16/32 字节 (SIMD) | 128/256 字节 (cache line) |
| 数据类型 | FP32/FP16/BF16 | 同上 + TF32/Tensor Core 专有 |

### 计算机科学家视角的关键要点

| 概念 | 含义 |
|------|------|
| 张量是多维数组 | 带形状、步长、数据类型的数据容器 |
| 内存布局很重要 | Row-major vs col-major 影响性能和 BLAS 互操作 |
| 步长实现零拷贝 | transpose/view/slice 旋转数据结构而非数据 |
| 设备是头等公民 | CPU/GPU 张量在内存空间上完全不同 |
| 连续性影响性能 | 非连续张量操作可能触发隐式拷贝或变慢 |

## 4. 三种视角的对照表

| 维度 | 数学家 | 物理学家 | 计算机科学家 |
|------|------|------|------|
| **张量是什么** | 多重线性映射 $V^*\times\cdots\times V \to \mathbb{F}$ | 满足坐标变换规则的几何对象 | 带 shape/stride/dtype 的多维数组 |
| **阶是什么意思** | 映射接收多少个输入向量 | 需要多少组变换系数 $\Lambda$ | 数组有多少个维度 |
| **秩（rank）** | $r+s$，逆变+协变阶数之和 | 同数学家 | `ndim`，维度数（与数学含义不同！） |
| **为什么叫"协变/逆变"** | 与输入空间 $V$ 还是 $V^*$ 有关 | 按坐标变换的 $\frac{\partial x}{\partial\bar{x}}$ 方向 | 不区分——深度学习总是在欧氏空间 |
| **需要坐标系吗** | 不需要（坐标无关） | 借助坐标系描述，但本质无关 | 隐式使用——行优先即坐标系 |
| **核心操作** | 张量积 $\otimes$、缩并（contraction） | 提升/降低指标，指标缩并 | reshape/transpose/slice/matmul |
| **约束条件** | 多重线性性 | 坐标协变性 | shape 兼容性、内存对齐 |
| **"改变形状"的意思** | 一般不改变（改变的是基的表示） | 一般不改变 | reshape/view（核心日常操作） |
| **张量本身和分量的关系** | 张量 ≠ 分量；分量是基下的表示 | 张量 ≠ 分量；定律用张量写 | 张量 = 数据本身；shape 是解释 |

### 一个具体的分歧："rank"

| 视角 | "rank-2 tensor" 的含义 |
|------|------|
| 数学家 | $(2,0)$ 型，接收 2 个对偶向量，返回标量 |
| 物理学家 | 需要 2 组变换系数，如应力张量 $\sigma^{ij}$ |
| 计算机科学家 | `ndim == 2`，即矩阵；称为 "2D tensor" 更合适 |

深度学习中，"rank" 几乎总是计算机科学家意义上的 `ndim`，而非数学的 `r+s`。

## 5. 在 LLAISYS 中的体现

### 代码中三种视角的痕迹

**计算机科学家视角（主导）：**
[`src/tensor/tensor.cpp`](file:///c:/Code/LLAISYS/llaisys/src/tensor/tensor.cpp) 中的 `Tensor` 类本质上是带 shape、strides、device 的多维数组。

```cpp
// 计算机科学家：张量 = 多维数组
Tensor* tensorCreate(size_t* shape, size_t ndim, 
                     llaisysDataType_t dtype, llaisysDeviceType_t device, int device_id);
Tensor* tensorView(Tensor* t, size_t* shape, size_t ndim);  // 零拷贝（仅改 strides）
Tensor* tensorPermute(Tensor* t, size_t* perm);              // 零拷贝（交换 strides）
```

**物理学家视角（残影）：**
CPU 算子中的循环嵌套反映了指标缩并：

```cpp
// linear_cpu.cpp 中的矩阵乘法本质上就是 (1,1) 型张量缩并
// C[i][j] = A[i][k] * B[j][k]  ← 爱因斯坦求和 C_{ij} = A_{ik} B_{jk}
for (int i = 0; i < m; i++)      // 协变指标
    for (int j = 0; j < n; j++)  // 协变指标
        for (int k = 0; k < p; k++) // 逆变指标（哑指标，求和）
            C[i][j] += A[i][k] * B[j][k];
```

self_attention 中的 Q·K^T 同样是指标缩并：
```
A_{ij} = Q_{ik} K_{jk}  ← (i,k) 和 (j,k) 在 k 上缩并
```

**数学家视角（残影）：**
线性层 $y = xW^T + b$ 本质上是 $(1,1)$ 型张量的缩并：
$$
y^i = W^i_j x^j + b^i
$$

### LLAISYS 中各种张量的类型对应

| LLAISYS 张量 | 形状 | 数学类型 | 物理含义 |
|------|------|:--:|------|
| `input` | `[m, k]` | $(1,1)$ 型 $x^j_{batch}$ | 逆变向量（行向量） |
| `weight` | `[n, k]` | $(1,1)$ 型 $W^i_j$ | 线性变换矩阵 |
| `output` | `[m, n]` | $(1,1)$ 型 $y^i_{batch}$ | 变换结果 |
| `Q` | `[L, Nh, d]` | $(3,0)$ 型 | 查询向量集合 |
| `K` | `[L, Nh, d]` | $(3,0)$ 型 | 键向量集合 |
| `V` | `[L, Nh, d]` | $(3,0)$ 型 | 值向量集合 |
| `attention_scores` | `[Lq, Lkv]` | $(0,2)$ 型 $A_{ij}$ | 注意力矩阵（类度量张量） |

### 为什么计算机科学视角主导深度学习框架

1. **欧氏空间假设**：深度学习在 $\mathbb{R}^n$ 中工作，度量张量 $g_{ij} = \delta_{ij}$，逆变和协变无区别
2. **坐标就是数据**：神经网络的输入/输出直接就是坐标分量，不需要"坐标无关"的概念
3. **性能优先**：内存布局（contiguous、alignment）直接决定硬件利用率，这是数学/物理视角不关心的
4. **设备异构**：CPU vs GPU 的内存空间差异是首要工程问题
