### 静态库构建顺序（由底向上）

```
llaisys-utils
    ↑
llaisys-device-cpu ──→ llaisys-device ──→ llaisys-core ──→ llaisys-tensor
                                                                    ↑
                                              llaisys-ops-cpu ──→ llaisys-ops
                                                                    ↑
                                                            llaisys (DLL)
```

## 二、C++ 源码依赖关系

### 2.1 入口层：`src/llaisys/`

```
src/llaisys/
├── ops.cc ──────────────────────────────────────────────────────────
│   #include "llaisys_tensor.hpp"
│   #include "../ops/add/op.hpp"
│   #include "../ops/argmax/op.hpp"
│   #include "../ops/embedding/op.hpp"
│   #include "../ops/linear/op.hpp"
│   #include "../ops/rearrange/op.hpp"
│   #include "../ops/rms_norm/op.hpp"
│   #include "../ops/rope/op.hpp"
│   #include "../ops/self_attention/op.hpp"
│   #include "../ops/swiglu/op.hpp"
│   → 对外 C API 封装（extern "C"），每个函数调用对应 ops::xxx()
│
├── tensor.cc ───────────────────────────────────────────────────────
│   #include "llaisys_tensor.hpp"
│   #include "../tensor/tensor.hpp"
│   → C API: tensorCreate / tensorDestroy / tensorXXX 系列
│
├── runtime.cc ──────────────────────────────────────────────────────
│   #include "../core/llaisys_core.hpp"
│   → C API: 运行时相关（内存分配/拷贝/同步/设备切换）
│
└── llaisys_tensor.hpp ──────────────────────────────────────────────
    → 内部类型定义: llaisysTensor_t（封装 tensor_t 的 C 结构体）
```

### 2.2 算子层：`src/ops/`

```
src/ops/<op_name>/
├── op.hpp ─────────── 算子接口声明
├── op.cpp ─────────── 设备分派逻辑
│   #include "../../core/llaisys_core.hpp"
│   #include "../../utils.hpp"
│   #include "cpu/<op>_cpu.hpp"
│   → 根据 deviceType 调用 cpu::<op>() 或 GPU 实现
│
└── cpu/
    ├── <op>_cpu.hpp ─ CPU 实现声明
    └── <op>_cpu.cpp ─ CPU 模板实现
        #include "../../../utils.hpp"
        → 模板函数支持 F32 / F16 / BF16
```

#### 具体算子列表

| 算子 | op.cpp | CPU 实现 | 依赖 |
|------|--------|----------|------|
| add | ✅ | add_cpu.cpp | utils.hpp |
| argmax | ✅ 已实现 | argmax_cpu.cpp | utils.hpp |
| embedding | ✅ 已实现 | embedding_cpu.cpp | utils.hpp |
| linear | ✅ 已实现 | linear_cpu.cpp | utils.hpp |
| rearrange | ✅ (空壳) | ❌ 未实现 | utils.hpp |
| rms_norm | ✅ 已实现 | rms_norm_cpu.cpp | utils.hpp |
| rope | ✅ 已实现 | rope_cpu.cpp | utils.hpp |
| self_attention | ✅ 已实现 | self_attention_cpu.cpp | utils.hpp |
| swiglu | ✅ 已实现 | swiglu_cpu.cpp | utils.hpp |

### 2.3 核心层：`src/core/`

```
src/core/
├── core.hpp ─────────────────── 聚合头文件
│   #include "allocator/allocator.hpp"
│   #include "context/context.hpp"
│   #include "runtime/runtime.hpp"
│   #include "storage/storage.hpp"
│
├── llaisys_core.hpp ─────────── 外部使用的聚合头文件
│   #include "../tensor/tensor.hpp"
│   #include "../device/runtime_api.hpp"
│   #include "core.hpp"
│
├── allocator/
│   ├── allocator.hpp ──── 抽象接口
│   └── naive_allocator.cpp ─ 简单 malloc/free 实现
│
├── context/
│   ├── context.hpp ────── 设备上下文单例声明
│   └── context.cpp ────── 上下文管理实现
│
├── runtime/
│   ├── runtime.hpp ────── 运行时抽象声明
│   └── runtime.cpp ────── 运行时实现
│
└── storage/
    ├── storage.hpp ────── 存储抽象声明
    └── storage.cpp ────── 存储实现
```

### 2.4 设备层：`src/device/`

```
src/device/
├── device_resource.hpp ──── 设备资源抽象接口
├── runtime_api.hpp ──────── 运行时 API 声明
├── runtime_api.cpp ──────── 设备分派
│
├── cpu/
│   ├── cpu_resource.hpp    #include "../device_resource.hpp"
│   ├── cpu_resource.cpp
│   └── cpu_runtime_api.cpp #include "../../utils.hpp"
│
└── nvidia/
    ├── nvidia_resource.cuh
    ├── nvidia_resource.cu
    └── nvidia_runtime_api.cu
```

### 2.5 Tensor 层：`src/tensor/`

```
src/tensor/
├── tensor.hpp ─── Tensor 类声明
│   → 定义 TensorMeta，Tensor 类（含 shape/strides/offset/storage）
│
└── tensor.cpp ─── Tensor 实现
    #include "../utils.hpp"
    #include "../core/core.hpp"
    → 实现 isContiguous() / view() / permute() / slice() / load()
```

### 2.6 工具层：`src/utils/`

```
src/utils/
├── types.hpp ─── 数据类型定义
│   → llaisysDataType_t 枚举、bf16_t / fp16_t 类型
│
├── types.cpp ─── 类型工具函数
│   → dsize() 获取类型字节大小
│   → cast() 类型转换
│
├── check.hpp ─── 断言/检查宏
│   → CHECK_ARGUMENT / CHECK_SAME_DEVICE / CHECK_SAME_DTYPE
│   → EXCEPTION_UNSUPPORTED_DEVICE / EXCEPTION_UNSUPPORTED_DATATYPE
│   → TO_BE_IMPLEMENTED
│
└── (其他工具文件)
```

## 四、Python 依赖关系

### 4.1 Python 包结构

```
python/llaisys/
│
├── __init__.py ────────── 包入口
│   from .tensor import Tensor
│   from .ops import Ops
│   from .runtime import Runtime
│
├── tensor.py ─────────── Tensor 类
│   from .libllaisys import LIB_LLAISYS, DataType, DeviceType
│   → 调用 LIB_LLAISYS.tensorCreate / tensorDestroy / tensorXXX
│
├── ops.py ────────────── 算子封装
│   from .libllaisys import LIB_LLAISYS
│   from .tensor import Tensor
│   → 每个静态方法调用 LIB_LLAISYS.llaisysXxx()
│
├── runtime.py ────────── 运行时封装
│   from .libllaisys import LIB_LLAISYS
│   → CPU/NVIDIA 运行时 API 封装
│
├── libllaisys/
│   ├── __init__.py ───── 加载 DLL
│   │   → ctypes.CDLL("llaisys.dll" / "llaisys.so")
│   │   → 定义 argtypes / restype
│   │
│   └── llaisys_types.py ─ 类型定义
│       → DataType / DeviceType 枚举
│       → llaisysTensor_t ctypes 结构体
│
└── models/
    ├── __init__.py
    └── qwen2.py ──────── Qwen2 模型推理实现
        from llaisys import Tensor, Ops, Runtime
```

```

    │       │                                │

    │       │
    │       └── Ops ─────→ ops.py ──────→ libllaisys/__init__.py ──→ llaisys.dll
    │
    └── from test_utils import * ─── test/test_utils.py
            │
            ├── random_tensor()
            ├── random_int_tensor()

```
