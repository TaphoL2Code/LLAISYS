## 项目概述

LLAISYS（Let's Learn AI SYStem）是一个教育性质的 AI 推理框架项目，旨在帮助 AI 工程师从零学习如何构建 AI 系统。项目使用 **C++17** 作为后端语言（编译为共享库，暴露 C 语言 API），使用 **Python** 作为前端（通过 `ctypes` 调用 C API），参照 PyTorch 的设计思想，实现了一个完整的神经网络推理引擎。

- 构建工具：**Xmake** + **MSVC/Clang/GCC**
- Python 包管理：**setuptools**（依赖 `torch`, `transformers`, `accelerate`）
- 验证方式：每个操作均与 PyTorch 的结果进行数值对比（手写底层，尝试优化）

## 关键设计模式

1. **C API + Python ctypes 桥接**：C++ 内部面向对象，对外导出纯 C 函数。Python 层通过 ctypes 调用，上层再封装为 Pythonic API。
2. **设备抽象**：通过 `LlaisysRuntimeAPI` 结构体（函数指针表）实现设备多态，新增设备只需实现一组函数指针并注册。
3. **线程局部 Context**：每个线程独立拥有 `Context` 实例，管理不同设备的 `Runtime`，天然线程安全。
4. **Storage 共享**：多个 Tensor 可共享同一个 `Storage`（通过 `shared_ptr`），`view`/`permute`/`slice` 等 view 操作零拷贝，仅改变元数据。
5. **算子分发**：每个算子在 `op.cpp` 中做设备类型分发 → 数据类型分发 → 调用具体计算内核（目前仅 CPU 实现）。
