# LLAISYS 项目树状结构图

> 以树状图形式阐述每个文件/模块的作用，从顶层入口到底层实现。

---

## 一、项目全景树

```
llaisys/                              ← 项目根目录
│
├── include/                           ← 【公共头文件层】对外暴露的 C API 契约
│   └── llaisys/                       ← 安装后用户 #include <llaisys/xxx.h>
│       ├── llaisys.h                  ← 全局枚举定义（dtype/device/memcpy/status）
│       ├── runtime.h                  ← LlaisysRuntimeAPI 函数指针表（设备操作抽象）
│       ├── tensor.h                   ← Tensor C API 声明
│       ├── ops.h                      ← 全部算子 C API 声明
│       └── models/
│           └── qwen2.h                ← Qwen2 模型推理 C API 声明
│
├── src/                               ← 【C++ 源码层】全部 C++ 实现
│   │
│   ├── utils.hpp                      ← 内部工具集入口（聚合所有子工具头文件）
│   ├── utils/                         ← 内部工具子模块
```

## 二、按模块职责分类

### 2.1 公共头文件（include/）

```
include/llaisys/
├── llaisys.h          ← 所有枚举：dtype/device/memcpy/status（被所有其他文件包含）
├── runtime.h          ← LlaisysRuntimeAPI 函数指针表（6 个函数指针）
├── tensor.h           ← 9 个 Tensor C API 函数声明
├── ops.h              ← 9 个算子 C API 函数声明
└── models/qwen2.h     ← 3 个 Qwen2 推理 C API 函数声明
```

### 2.2 工具层（src/utils/）

```
src/utils.hpp          ← 聚合入口（#include 下面三个文件）
├── types.hpp          ← dsize()/dtype_to_str()/device_to_str() 声明
├── types.cpp          ← 实现：dtype 枚举→字节数 的 switch-case
└── check.hpp          ← CHECK_ARGUMENT/ASSERT/TO_BE_IMPLEMENTED 宏定义
```

### 2.3 核心层（src/core/）

```
src/core/
├── allocator/
│   ├── allocator.hpp        ← 抽象接口：virtual allocate()/deallocate() = 0
│   └── naive_allocator.cpp  ← 唯一实现：malloc/free
│
├── context/
│   └── context.cpp          ← 线程级单例：thread_local Context
│                             ← 关键方法：setDevice() 切换当前 Runtime
│                             ← 关键方法：runtime() 获取当前 Runtime
│
├── runtime/
│   └── runtime.cpp          ← 封装 RuntimeAPI：allocate()/deallocate()/api()
│                             ← 通过 DeviceResource 工厂创建具体 RuntimeAPI
│
└── storage/
    └── storage.cpp          ← 内存包装：_memory(byte*)/_deviceType/_size
                             ← create() 调 Runtime::allocate()
                             ← 析构时调 Runtime::deallocate()
```

### 2.4 设备层（src/device/）

```
src/device/
├── runtime_api.hpp          ← 抽象 RuntimeAPI：存储 _api 函数表，提供 api()
├── device_resource.hpp      ← 抽象工厂：virtual createRuntimeAPI(id) = 0
│
└── cpu/
    ├── cpu_resource.cpp     ← 注册 CPU 设备到全局工厂表
    └── cpu_runtime_api.cpp  ← ★ 填充 CPU 函数表：
                              ←   malloc_device → malloc
                              ←   free_device   → free
                              ←   memcpy_sync   → memcpy
                              ←   memcpy_async  → memcpy
                              ←   memset_device → memset
                              ←   device_synchronize → 空操作
```

### 2.5 张量层（src/tensor/）

```
src/tensor/
├── tensor.hpp               ← TensorMeta{_dtype, shape, strides}
│                             ← Tensor{_meta, _storage, _offset}
│                             ← 接口：create/load/isContiguous/view/permute/slice/debug
│
└── tensor.cpp               ← ★ 核心实现：
    create()                 ← 算 strides（行优先），分配 Storage
    data()                   ← _storage->memory() + _offset
    elementSize()            ← dsize(_meta.dtype)
    numel()                  ← shape 连乘
    ndim()                   ← shape.size()
    load(src)                ← H2D memcpy_sync
    isContiguous()           ← strides[i] == strides[i+1] * shape[i+1]
    view(shape)              ← 验证 numel，重算 strides，共享 storage
    permute(order)           ← 重排 shape 和 strides，共享 storage
    slice(dim, start, end)   ← 改 shape[dim]，改 offset，共享 storage
    debug()                  ← D2H memcpy，逐元素打印
```

### 2.6 算子层（src/ops/）

以 `add` 为例展示三层结构：

```
src/ops/add/
├── op.hpp        ← add(a, b) → tensor 声明
├── op.cpp        ← 调度层：检查 shape/dtype→创建输出→调 CPU kernel
└── cpu/
    ├── add_cpu.hpp   ← add_cpu_kernel 声明
    └── add_cpu.cpp   ← 实现：获取 data_ptr，for 循环逐元素 a[i]+b[i]

其他算子（argmax/embedding/linear/rms_norm/rope/self_attention/swiglu/rearrange）：
├── op.hpp        ← 声明（已完成）
└── op.cpp        ← 调度层（待实现，Assignment 2）
```

### 2.7 C API 层（src/llaisys/）

```
src/llaisys/
├── llaisys_tensor.hpp   ← get_tensor_from_handle(): void* → shared_ptr<Tensor>
│
├── tensor.cc            ← extern "C" 导出：
│   tensorCreate()       ← Tensor::create()
│   tensorLoad()         ← tensor->load()
│   tensorView()         ← tensor->view()
│   tensorPermute()      ← tensor->permute()
│   tensorSlice()        ← tensor->slice()
│   tensorIsContiguous() ← tensor->isContiguous()
│   tensorDebug()        ← tensor->debug()（含 D2H memcpy）
│   tensorDestroy()      ← 释放 shared_ptr
│
├── runtime.cc           ← extern "C" 导出：
│   runtimeInit()        ← 注册 CPU 设备
│   runtimeDestroy()     ← 清理
│
└── ops.cc               ← extern "C" 导出：
    opsAdd()             ← ops::add(a, b)
    opsArgmax()          ← ops::argmax(a, dim)
    opsEmbedding()       ← ops::embedding(w, idx)
    ...（全部 9 个算子）
```

### 2.8 Python 绑定层（python/llaisys/）

```
python/llaisys/
├── __init__.py              ← 包入口
│
├── libllaisys/              ← ctypes 底层（直接操作 DLL）
│   ├── __init__.py          ← ★ 加载 llaisys.dll/cdll.LoadLibrary
│   │                         ← 设置所有 C 函数的 argtypes/restype
│   ├── llaisys_types.py     ← ctypes 类型映射表
│   ├── tensor.py            ← 声明 tensorCreate/Load/View/Debug 等
│   ├── runtime.py           ← 声明 runtimeInit/Destroy
│   └── ops.py               ← 声明 opsAdd/Argmax/Linear 等
│
├── tensor.py                ← Python Tensor 类（__init__/load/debug/view/permute/slice）
├── runtime.py               ← 初始化 Runtime
├── ops.py                   ← 算子封装（add/argmax/linear...）
│
└── models/
    └── qwen2.py             ← Qwen2 推理（权重加载+forward 循环）
```

### 2.9 构建系统

```
xmake.lua           ← 9 个 target 的依赖关系：
├── llaisys-utils       ← src/utils/types.cpp
├── llaisys-core        ← core/allocator + core/context + core/runtime + core/storage
├── llaisys-device      ← src/device/runtime_api.cpp
├── llaisys-device-cpu  ← src/device/cpu/cpu_runtime_api.cpp + cpu_resource.cpp
├── llaisys-tensor      ← src/tensor/tensor.cpp
├── llaisys-ops         ← 9 个算子的 op.cpp
├── llaisys-ops-cpu     ← add 的 CPU kernel
├── llaisys             ← src/llaisys/*.cc（最终 DLL）
└── llaisys_python      ← Python 绑定（cpython）

xmake/cpu.lua       ← 编译器选项：-march=native, -O3, -DNDEBUG, -fopenmp
```

## 三、数据流 & 调用链（从一个请求的视角）

```
用户 Python 代码
    │
    ├── tensor = Tensor(shape, dtype)         → python/llaisys/tensor.py
    │       └── ct.CDLL.tensorCreate(...)     → python/llaisys/libllaisys/__init__.py
    │           └── tensorCreate()            → src/llaisys/tensor.cc
    │               └── Tensor::create()      → src/tensor/tensor.cpp
    │                   ├── 算 strides（行优先）
    │                   └── Storage::create() → src/core/storage/storage.cpp
    │                       └── context().runtime().allocate()
    │                           └── Runtime::allocate()  → src/core/runtime/runtime.cpp
    │                               └── RuntimeAPI::api()->malloc_device()
    │                                   └── CPU: malloc()
    │
    ├── tensor.load(torch_data_ptr)           → python/llaisys/tensor.py
    │       └── ct.CDLL.tensorLoad(...)       → src/llaisys/tensor.cc
    │           └── tensor->load(src)         → src/tensor/tensor.cpp
    │               └── context().runtime().api()->memcpy_sync(H2D)
    │                   └── CPU: memcpy(data(), src, size)
    │
    ├── result = ops.add(a, b)                → python/llaisys/ops.py
    │       └── ct.CDLL.opsAdd(...)           → src/llaisys/ops.cc
    │           └── ops::add(a, b)            → src/ops/add/op.cpp
    │               └── add_cpu_kernel(...)   → src/ops/add/cpu/add_cpu.cpp
    │                   └── for i: out[i]=a[i]+b[i]
    │
    └── tensor.debug()                        → python/llaisys/tensor.py
            └── ct.CDLL.tensorDebug(...)      → src/llaisys/tensor.cc
                └── tensor->debug()           → src/tensor/tensor.cpp
                    ├── memcpy_sync(D2H)      ← 从设备拷回 CPU
                    └── 逐元素打印
```
