## 阅读顺序总览

```
第 0 层  include/llaisys.h  ← 枚举类型
         include/llaisys/runtime.h  ← 函数表结构体
         include/llaisys/tensor.h   ← Tensor C API
         include/llaisys/ops.h      ← 算子 C API
         include/llaisys/models/qwen2.h  ← 模型 C API
              │
第 1 层  src/utils.hpp  ← 工具头文件
         src/utils/check.hpp  ← 断言宏
         src/utils/types.hpp + .cpp  ← dtype 转换
              │
第 2 层  src/core/allocator/allocator.hpp  ← 抽象 Allocator
         src/core/allocator/naive_allocator.hpp + .cpp  ← malloc/free
              │
第 3 层  src/core/context/context.hpp + .cpp  ← 线程级 Context
              │
第 4 层  src/device/runtime_api.hpp + .cpp  ← 抽象 RuntimeAPI
         src/device/device_resource.hpp  ← 工厂方法
         src/device/cpu/cpu_resource.hpp + .cpp  ← CPU 注册
              │
```
